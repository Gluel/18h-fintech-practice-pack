# M1 요구사항

## 1. 사용자
주간 보고서를 처음 작성하는 경제지표 초보 실무자. 실제 인터뷰로 검증한 사용자가 아닌 수업용 가설입니다.

## 2. 문제 가설
연평균 환율을 현재 환전 가격으로 오해할 수 있습니다. 숫자 옆에서 의미를 확인하기 어렵다는 가설을 검사합니다.

## 3. 입력
index.html, data/macro_sample.js, data/macro_sample.json. World Bank KOR 2015~2024, 3지표 30관측값. 확보일 2026-08-25. docs/source_policy.md 참조.

## 4. 핵심 기능
차트 가까이에 접고 펼치는 지표 설명을 추가합니다. 선택한 지표의 이름·원본 단위·관측 범위·확보일·해석 한계가 함께 바뀌어야 합니다. 출처 버튼은 유지합니다.

## 5. 제외
외부 API·패키지·모델 호출·실거래·계좌정보를 추가하지 않습니다. 원본값·계산·출처 모달·기존 지표/기간 선택은 변경하지 않습니다. data/는 읽기 전용입니다.

## 6. 완료조건
docs/test_log.md의 T1~T5를 실제 브라우저에서 확인합니다. 2025~2026은 미보유로 표시하며 0이나 추정값으로 채우지 않습니다. 실행하지 못한 검사는 미실행입니다.
