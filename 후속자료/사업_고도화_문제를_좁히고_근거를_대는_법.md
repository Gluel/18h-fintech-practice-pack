# 사업·서비스 고도화 — 문제를 좁히고, 근거를 대고, AI로 먼저 두들겨 보기

> **쓰는 법**: 이 파일 전체를 AI 에게 붙여넣고, 각 장 끝의 「그대로 붙여넣을 문장」을 이어서 치면 됩니다.
>

3일 동안 만든 것이 **돌아간 다음**에 여는 자료입니다.
아직 화면이 안 도는 분은 이 파일을 닫고 M5·M6 로 돌아가세요 — 순서가 있습니다.

---

## 1. 문제를 한 번 더 좁힙니다

넓은 문제는 **누구에게 물어봐야 할지를 알려주지 않습니다.**

| 단계 | 예시 문장 | 무엇이 생기나 |
| --- | --- | --- |
| 처음 | 사회초년생이 금융 뉴스를 봐도 판단을 미룬다 | (아직 없음) |
| 한 번 좁힘 | 첫 주식을 사려는 1~2년차가 **금리 뉴스**를 봤을 때 무엇을 볼지 모른다 | 어떤 상황인지가 정해짐 |
| 두 번 좁힘 | **굴릴 돈 1천만원 이하**인 사람이 **「기준금리 동결」** 기사에서 예금·대출 결정을 못 한다 | 찾아갈 사람 · 물어볼 질문 · 만들 화면 1개 |

> 좁히는 것은 **시장을 줄이는 일이 아니라 처음 만날 사람을 정하는 일**입니다.
> 넓게 두면 아무도 안 만나집니다.

**그대로 붙여넣을 문장**

```
내 문제 한 줄은 <여기에> 입니다.
이 문장을 «상황»과 «조건» 축으로 두 번 좁힌 문장 3개씩 만들어 줘.
좁힐 때마다 「이렇게 좁히면 누구를 찾아갈 수 있는가」를 한 줄로 같이 적어 줘.
내가 확인하지 않은 사실은 넣지 말고, 필요하면 「확인 필요」라고 표시해 줘.
```

## 2. 페르소나를 «한 사람»까지 내립니다

M5 에서 만든 페르소나가 아직 「사회초년생」 수준이면 화면을 못 만듭니다.

| 칸 | 넓은 판 (쓸 수 없음) | 좁힌 판 (쓸 수 있음) |
| --- | --- | --- |
| 누구 | 사회초년생 | 입사 2년차 · 월 실수령 280만 전후 · 통장에 1천만원 |
| 언제 | 뉴스를 볼 때 | 출근길에 금리 기사 알림을 받았을 때 |
| 무엇이 막히나 | 판단이 어렵다 | 예금을 더 둘지, 지금 넣을지 **오늘 안에** 못 정한다 |
| 지금 어떻게 하나 | 검색한다 | 포털 → 증권 앱 → 친구 카톡 → 창 닫음 |
| 표시 | — | **인터뷰하지 않았으므로 가설입니다** |

> 인터뷰나 통계를 **지어내지 않습니다.** 조사하지 않았으면 「가설」이라고 적습니다.
> 3일 동안 지킨 「확인한 것과 확인 안 한 것을 나눠 적는다」가 여기서도 그대로입니다.

**그대로 붙여넣을 문장**

```
아래 페르소나를 «한 사람»까지 좁혀 줘.
지금 판: <여기에 붙여넣기>
누구 / 언제 / 무엇이 막히나 / 지금 어떻게 하나 네 칸으로 다시 쓰고,
각 칸 옆에 「이건 내가 확인한 것인가, 가설인가」를 표시해 줘.
확인하지 않은 것을 확인한 것처럼 적지 마.
```

## 3. SOM 한 칸에만 근거를 댑니다

**순서가 중요합니다.** 좁히기 **전에** 시장 크기를 재면 항상 커 보이고, 커 보이면 안 좁힙니다.

| 칸 | 뜻 | 근거가 필요한가 |
| --- | --- | --- |
| TAM (전체) | 이 문제를 가진 사람 전부 | 참고만 |
| SAM (내가 닿는 범위) | 내 채널·지역·조건으로 닿을 수 있는 사람 | 참고만 |
| **SOM (1년 안에 만날 사람)** | **1년 안에 실제로 만나서 쓰게 할 수 있는 사람 수** | **여기에만 근거를 댑니다** |

### 근거로 쓸 수 있는 것 / 없는 것

| 쓸 수 있음 | 쓸 수 없음 |
| --- | --- |
| 공개 통계 (출처 + 기준일 같이) | 「~라고 합니다」 |
| 내가 직접 센 것 (어떻게 셌는지 같이) | AI 가 준 숫자 |
| 인터뷰한 사람 수 (몇 명에게 물었는지) | 출처 없는 기사 인용 |

> 못 찾으면 **「모름」이라고 적습니다.**
> 지어낸 숫자 하나가 나머지 판을 전부 못 믿게 만듭니다.

**그대로 붙여넣을 문장**

```
내 서비스의 TAM · SAM · SOM 세 칸 «틀»만 만들어 줘. 숫자는 넣지 마.
각 칸에 「이 숫자를 구하려면 어떤 공개 통계를 어디서 찾아야 하는지」를 적어 주고,
SOM 칸에는 「내가 직접 세려면 무엇을 세면 되는지」를 3가지 방법으로 적어 줘.
출처를 모르는 숫자는 절대 넣지 마.
```

## 4. 사람을 만나기 «전»에 AI로 먼저 두들겨 봅니다 (합성 소비자)

AI 에게 「내 서비스 어때?」라고 물으면 **무조건 좋다고 합니다.** 그래서 반대로 시킵니다.

**① 안 쓸 이유를 받는다**

```
아래 페르소나 한 사람이 되어서, 내 서비스 설명을 읽고
«안 쓸 이유» 5개를 말해 줘. 좋은 점은 말하지 마.

페르소나: <3장에서 좁힌 한 사람>
서비스 설명: <내 랜딩 문구 그대로>
```

**② 두 칸으로 나눈다**

```
방금 나온 5개를,
(가) 내가 «물어봐서» 확인할 수 있는 것
(나) 직접 «써 봐야» 아는 것
으로 나눠 줘. (가)는 인터뷰 질문 형태로 다시 써 줘.
```

**③ 세 개만 들고 실제 사람을 만난다**

(가)에서 나온 질문 중 **3개만** 고릅니다. 그리고 실제로 한 사람을 만납니다.

### 여기서 지켜야 할 경계

- 합성 응답은 **「물어볼 질문을 고르는 데」만** 씁니다.
- AI 가 한 말을 **근거로 적지 않습니다.** 근거는 실제 사람이 한 말입니다.
- 페르소나 카드에 **「합성 응답으로 뽑은 질문」**이라고 표시해 둡니다.

> 3일 동안 계속한 구분과 같습니다 — **관측한 사실 / 내 해석 / 아직 확인 안 한 가설.**

---

## 5. 다 하고 나면 이 순서로 돌아옵니다

```
문제 좁히기 → 페르소나 1명 → SOM 근거 → 합성으로 질문 고르기 → 사람 1명 만나기
                                                                      │
        ← 받은 말로 문제 한 줄을 다시 고친다 ←───────────────────────┘
```

**한 바퀴에 한 가지만 바꿉니다.** 문제도 바꾸고 페르소나도 바꾸고 화면도 바꾸면,
반응이 달라져도 무엇 때문인지 알 수 없습니다.
