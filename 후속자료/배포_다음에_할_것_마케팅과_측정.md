# 배포 다음에 할 것 — 마케팅 자동화와 측정

> 부산대 미래시민교육원 핀테크 AI 18H · 3일 과정 수료자용 · 2026-09-12
> 만든 사람: 주식회사 코스타트 · 박정근

배포까지 하셨으면 바로 부딪히는 벽이 있습니다. **아무도 안 옵니다.**
주소를 아는 사람이 나 하나입니다. 여기서부터는 만드는 일이 아니라 굴리는 일인데,
**구조는 3일 동안 배운 것과 같습니다.**

---

## 1. 알리는 일도 루프입니다

```
전략 한 줄 ─▶ 가설 한 개 ─▶ 만들기 ─▶ 내보내기 ─▶ 숫자 보기 ─▶ 다시 가설
                                                    │
                                    반응 좋은 한 개를 다른 채널로 파생
```

| 단계 | 정할 것 | 3일 과정의 무엇과 같은가 |
| --- | --- | --- |
| 전략 | 누구에게 · 무엇을 · 어떤 행동을 원하나 | M2 린캔버스 문제·고객 |
| 가설 | **조작 변수 하나**와 기각선 (예: 「이 문구면 반응 2% 넘는다」) | M5 요구사항 R-01 |
| 제작 | 쓰면 안 되는 문구부터 정한다 (「100% 보장」 같은 단정) | M2 「확보 안 한 것은 쓰지 않는다」 |
| 배포 | 내보내기 **직전에 사람이 한 번 본다** | M6 배포 전 점검 |
| 분석 | 정한 지표 **하나만** 본다 | M4 검산 |
| 폐루프 | 반응 좋은 것 하나를 다른 채널로 | M6 회귀 확인 |

> **한 번에 한 변수.** 제목도 바꾸고 그림도 바꾸고 시간도 바꾸면,
> 반응이 좋아져도 무엇 때문인지 모릅니다.
> 3일 내내 「한 번에 하나만 고친다」고 했던 것과 같은 이야기입니다.

**보낼지 말지는 사람이 누릅니다.** 기계가 대신 누르게 두지 않습니다.

## 2. 측정 — 「무엇을 재지 않을지」부터 정합니다

가장 흔한 실수는 **도구부터 붙이고 숫자를 다 모아 놓고 아무것도 안 보는 것**입니다.

순서는 이렇습니다.

1. **한 줄** — 이 서비스가 쓸모 있으면 무엇이 달라지나?
2. **행동 하나** — 그 한 줄을 셀 수 있는 사용자 행동 «하나»를 고른다
3. **그제서야 도구** — 그 행동 하나만 재도록 붙인다
4. **안 재기로 한 것도 적는다**

> 예) 「체류시간은 안 봅니다 — 오래 봤다고 도움이 된 건 아니라서요.」
> 이 한 문장이 나중에 여러분을 구합니다.
>
> 이력서에 「데이터 기반 의사결정」이라고 쓸 때도 마찬가지입니다.
> 「지표를 봤습니다」가 아니라 **「무엇을 재지 않기로 정했는지」**가 판단의 증거입니다.

**그대로 붙여넣을 문장**

```
내 서비스는 <한 줄>입니다.
「이게 쓸모 있으면 무엇이 달라지나」를 기준으로,
재야 할 사용자 행동 후보 5개와 «재지 않기로 할 것» 5개를 표로 만들어 줘.
각 줄에 왜 그렇게 판단했는지 한 문장씩 붙여 줘. 도구 이름은 아직 쓰지 마.
```

행동 하나를 정한 다음에야 측정 도구를 붙입니다.

```
위에서 정한 행동 «하나»만 재려고 합니다.
그 행동을 재려면 화면의 어디에서 무엇이 일어났을 때 기록해야 하는지,
이벤트 이름 후보와 같이 남길 값 3개를 표로 만들어 줘.
개인을 식별할 수 있는 값은 넣지 마.
```
