가이드 ② GitHub 저장·복원

오늘 만든 것을 창고에 넣고, 내일 아침 다시 꺼냅니다.

왜 하나요? ① 이 PC는 재부팅하면 지워집니다 ② 3일을 이어서 해야 합니다 ③ 오후에 웹 주소를 만들 때 이 창고를 연결합니다.
1
(수업 전) 가입과 이메일 인증
① 할 일

github.com 에서 가입하고 이메일 인증까지 끝냅니다.

인증하지 않으면 저장소를 만들 수 없습니다.

② 성공하면 보이는 화면

로그인한 상태로 github.com 이 열립니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

인증 메일이 없으면 스팸함을 확인하세요. 휴대폰에서 메일을 볼 수 있어야 합니다.

2
저장소 만들기
① 할 일

오른쪽 위 + → New repository.

이름은 영어 소문자와 하이픈으로. 예: fintech-news-report

Private 를 고릅니다.

② 성공하면 보이는 화면

Create repository 를 누르면 빈 저장소가 생깁니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

이름에 한글·공백이 있으면 거부됩니다. 영어 소문자로 바꾸세요.

3
폴더를 열고 전체 선택
① 할 일

탐색기에서 파일이 보이는 폴더를 엽니다.

Ctrl + A 로 전체를 선택합니다.

⚠️ 폴더 자체를 끌면 index.html 이 한 칸 아래로 내려가 나중에 404 가 납니다.

② 성공하면 보이는 화면

파일들이 파랗게 선택됩니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

폴더가 하나만 보이면 그 폴더를 열고 다시 Ctrl+A 하세요.

4
끌어 놓고 Commit
① 할 일

GitHub 의 Add file → Upload files 로 갑니다.

선택한 파일을 점선 상자로 끌어 놓습니다.

아래 Commit changes 를 누릅니다.

② 성공하면 보이는 화면

파일 목록이 저장소에 나타납니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

파일이 25MB 를 넘거나 100개를 넘으면 나눠 올립니다. 영상은 올리지 않습니다.

5
맨 위 확인
① 할 일

저장소 목록에서 index.html 이 맨 위에 있는지 봅니다.

② 성공하면 보이는 화면

index.html 이 폴더가 아니라 맨 위에 있습니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

한 칸 아래에 있으면 3번을 다시 합니다. 이대로 배포하면 404 입니다.

6
(다음 날) 복원하기
① 할 일

Code ▾ → Download ZIP

내려받아 모두 압축 풀기 하고 Claude 앱에서 폴더를 엽니다.

README 진행 로그를 읽고 이어서 해줘.

② 성공하면 보이는 화면

어제 파일이 그대로 열립니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

새 기기라 이메일 확인 코드가 옵니다(1시간 유효). 휴대폰에서 메일을 여세요.

7
퇴실 전 로그아웃
① 할 일

Settings → Sessions 에서 로그인을 해제하거나 오른쪽 위 프로필 → Sign out.

② 성공하면 보이는 화면

다음 사람이 내 계정으로 들어갈 수 없습니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

브라우저에 비밀번호를 저장했다면 저장 안 함으로 지우세요.
