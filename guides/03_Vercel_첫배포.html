가이드 ③ Vercel 첫 배포

창고에 둔 파일을 웹 주소로 겁니다. (M2 6교시)

무료 요금제 주의. 개인·비상업 용도입니다. 결제 버튼·광고·실제 판매 문구·가입 폼을 넣지 않습니다. 화면 하단에 「수업 과제 데모 · 투자 판단 근거 아님」을 적습니다.
1
GitHub 으로 가입
① 할 일

vercel.com → Continue with GitHub.

새 비밀번호를 만들지 않습니다.

② 성공하면 보이는 화면

Vercel 대시보드가 열립니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

권한 화면이 안 뜨면 브라우저 팝업 차단을 확인하세요.

2
저장소 가져오기
① 할 일

Add New → Project 에서 내 저장소를 고르고 Import.

② 성공하면 보이는 화면

Framework Preset 은 Other, Root Directory 는 ./ 입니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

저장소가 안 보이면 개인 계정에 만든 것이 맞는지 확인하세요. 조직(Organization) 소유 비공개 저장소는 무료 요금제에서 안 됩니다.

3
Deploy
① 할 일

Deploy 를 누르고 1~2분 기다립니다.

② 성공하면 보이는 화면

축하 화면과 짧은 주소가 나옵니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

404 가 나오면 index.html 이 저장소 맨 위에 있는지 확인하세요(가이드 ② 5번).

4
시크릿 창으로 확인
① 할 일

Ctrl + Shift + N 으로 시크릿 창을 열고 짧은 주소를 붙여 넣습니다.

프로젝트명.vercel.app 만 씁니다.

② 성공하면 보이는 화면

로그인 없이도 내 화면이 열립니다. 이 주소를 제출합니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

안 열리면 ①대표(짧은) 주소가 맞는지 ②로그인 없는 창인지 ③Vercel 의 배포 보호 설정을 차례로 확인합니다. 주소 길이만으로 단정하지 않습니다.

5
리포트도 확인
① 할 일

주소 뒤에 /report.html 을 붙여 열어 봅니다.

② 성공하면 보이는 화면

리포트 표가 보입니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

404 면 파일명 대소문자를 확인하세요. Report.html ≠ report.html 입니다.

6
다시 올리면 자동 배포
① 할 일

GitHub 에 파일을 다시 올리면 Vercel 이 자동으로 다시 배포합니다.

Deployments 화면에 새 줄이 생깁니다.

② 성공하면 보이는 화면

새 배포가 Ready 가 되면 주소를 새로고침해 확인합니다.

📷 캡처 자리 — 9/12 실습 PC에서 이 화면을 캡처해 이 자리에 넣는다
③ 안 되면

새 줄이 없으면 GitHub 업로드가 커밋되지 않은 것입니다.

Vercel 이 막히면 — GitHub Pages(저장소를 공개로 바꿔야 하고 반영에 최대 10분) 또는 Netlify Drop(로그인 없이 폴더를 끌어 놓기). 둘 다 안 되면 패들렛에 ZIP 과 캡처를 올리고 미완료로 기록합니다.
