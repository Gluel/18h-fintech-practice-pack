# AI 요청 예시

## 1. 읽기
```text
현재 폴더의 README.md, index.html, data/macro_sample.js, docs/requirements.md를 읽어주세요. 파일을 수정하지 말고 화면이 어떻게 데이터를 읽는지, 이미 있는 출처 기능과 아직 없는 설명 기능을 구분해주세요. 실제 파일명으로 답하고 모르면 확인이 필요하다고 해주세요.
```

## 2. 준비 운동
```text
index.html의 본문 h1 제목만 우리 팀 경제지표로 바꿔주세요. 데이터·계산·출처·지표 선택·기간 선택은 보존하세요. 변경한 위치와 제가 확인할 방법을 설명해주세요. 다른 변경은 하지 마세요.
```

## 3. 계획
```text
docs/requirements.md의 여섯 항목과 docs/test_log.md의 다섯 검사를 읽고 설명 기능 하나의 구현 계획을 제시해주세요. data/는 읽기 전용입니다. 필요한 파일과 기존 정보를 재사용할 위치만 설명하고, 아직 수정하지 마세요.
```

## 4. 구현
```text
확인한 계획 범위에서 설명 기능 하나만 구현해주세요. 이름·원본 단위·관측 범위·확보일·해석 한계는 제공 데이터에서 가져오세요. 현재 선택 지표와 기간을 따르고 미보유를 0으로 채우지 마세요. 기존 출처 버튼과 원본값은 보존하세요. 바뀐 파일과 직접 검사할 T1~T5를 알려주세요. 실행하지 않은 검사를 통과라고 하지 마세요.
```

## 5. 수정 요청
```text
검사 ID: [T번호]
조작: [어떤 지표/기간/버튼]
기대 결과: [요구사항]
실제 결과: [직접 본 현상]
이 오류만 수정해주세요. 원본 데이터와 다른 기능은 보존하고, 확인하지 않은 결과는 미실행으로 남겨주세요.
```
