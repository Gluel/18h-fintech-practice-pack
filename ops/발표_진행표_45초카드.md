# 발표 진행표 · 45초 대본 카드 (M6 6교시)

## 왜 45초인가
25명 × 1분 + 전환 15초 = **31.3분**. 30분 안에 안 들어갑니다.
그래서 **45초**로 줄이고, 강사가 주소 탭을 **미리** 엽니다.

| 시각 (6교시) | 할 일 | 누가 |
|---|---|---|
| 0~10분 | 랜딩페이지 완성 → 배포 전 점검 → GitHub → Vercel 재배포 | 수강생 |
| 10~13분 | 패들렛 최종 제출 (`D3-M6_번호_이름` · 짧은 주소 · **랜딩 캡처 1장 필수**) | 수강생 |
| 13~16분 | **번호순으로 짧은 주소 탭 25개 미리 열기** · 안 열린 번호 표시 | 강사 |
| 16~41분 | **발표 45초 × 25명** (5초 안에 안 열리면 패들렛 캡처로 전환) | 전체 · 타이머 = 운영 매니저 |
| 41~45분 | 미제출·지연자 발표 · 강사 총평 | 강사 |
| 45~50분 | 마무리 · 수료 후 로드맵 · 만족도조사 QR | 강사 |

## 45초 대본 카드 (그대로 읽으셔도 됩니다)

> **① 문제 (15초)** — 저는 「____」 하는 사람이 「____」 때문에 불편한 문제를 골랐습니다.
>
> **② 동작 (20초)** — 화면을 보시면 ____ 를 누르면 ____ 가 나옵니다. 데이터는 ____ 에서 받았습니다.
>
> **③ 검사·한계 (10초)** — ____ 를 검사했고 ____ 는 통과, ____ 는 아직입니다. 다음에는 ____ 를 고치겠습니다.

## 진행 규칙
- 번호순으로 부릅니다. 이름을 외치지 않고 **번호**로 부릅니다.
- 주소가 5초 안에 안 열리면 **바로 패들렛 캡처**로 넘어갑니다. 기다리지 않습니다.
- 45초가 되면 타이머가 알립니다. 말을 끊지 않고 **다음 문장에서** 넘깁니다.
- 질문은 발표 중에 받지 않습니다. 총평 시간에 모아서 합니다.
